# Last City zone artwork

Generated with the built-in image-generation tool for the October 4, 2026 world and story update. Each asset is a 1536 × 1024 PNG. The five source outputs were visually inspected and copied into this project without replacing the existing pet assets.

| Zone | Asset | Use |
| --- | --- | --- |
| Ashfall Outpost | [ashfall.png](ashfall.png) | Amber ruins and restored beacon |
| Overgrown Depot | [depot.png](depot.png) | Moss-covered railway and gate |
| Copperworks Foundry | [foundry.png](foundry.png) | Furnaces and engine machinery |
| Neon Relay | [relay.png](relay.png) | Violet relay towers and skyline |
| Celestial Citadel | [citadel.png](citadel.png) | Luminous reactor above the clouds |

Artwork appears in the active zone banner, activity scenes, and recovered story pages. Only the currently rendered artwork is requested by the browser. Dark CSS overlays keep game controls and text readable. Theme colors and all gameplay controls remain native HTML/CSS, so the game stays usable if artwork does not load.
